# Infrastructure

Kalıcılık adaptörleri uygulama sözleşmeleri üzerinden kullanılır; React bileşenleri
ve hesaplama motoru doğrudan depolamaya erişmez. Aşama 5'te localStorage repository,
depolamadan bağımsız JSON yedekleme ve v3 JSON dönüştürücüsü eklendi.

Sözleşmeler, hata durumları, veri koruma ve geçiş sınırları:
[Kalıcılık dokümanı](persistence/README.md). Dosya/Excel ve React entegrasyonu bu
aşamada yoktur.
